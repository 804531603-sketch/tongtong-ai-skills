# 专业品酒笔记模板（可直接套用）

> 使用说明：把【】替换成你的实际观察；() 是提示，写完后删掉。视觉/嗅觉/味觉按实际勾选或描述。

## 基本信息
- 酒款：【酒庄 / 产区 / 年份 / 品种】
- 类型：【干红 / 干白 / 桃红 / 起泡 / 甜酒】
- 饮用温度：【℃】  侍酒方式：【直饮 / 醒酒__分钟】

## 视觉（Visual）
- 色泽：【柠檬绿 / 金黄 / 宝石红 / 紫红 / 砖红 / 琥珀】
- 清澈度：【清澈透亮 / 轻微浑浊】
- 浓稠度/挂杯：【轻 / 中 / 重】

## 嗅觉（Nose）—— 三层香气
- 一类香气（品种）：【黑樱桃、醋栗、柑橘、花香……】
- 二类香气（发酵）：【酵母、面包、奶油、饼干……】
- 三类香气（陈年）：【皮革、菌菇、焦油、坚果、蜂蜜……】
- 香气浓度：【淡 / 中 / 浓】  纯净度：【干净 / 有杂味】

## 味觉（Palate）
- 甜度：【干 / 半干 / 半甜 / 甜】
- 酸度：【低 / 中 / 高】
- 单宁（红）：【低 / 中 / 高，细腻 / 粗糙】
- 酒精度：【低 / 中 / 高】
- 酒体：【轻 / 中 / 饱满】
- 风味浓度：【淡 / 中 / 浓】
- 余味长度：【短(<3s) / 中(3–5s) / 长(>5s)】
- 平衡度：【平衡 / 偏向__(酸/甜/酒精/单宁过强)】

## 结论
- 质量判断：【普通 / 优质 / 精品 / 收藏级】
- 适饮期：【现在喝 / 可陈年__年】
- 配餐建议：【红肉 / 海鲜 / 禽类 / 奶酪 / 甜点 / 亚洲菜……】
- 一句话点评：【用体验感的话总结，比如「像咬了口黑樱桃，单宁丝滑，配牛排刚好」】
